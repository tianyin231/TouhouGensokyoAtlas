# 兽道溪桥—夜雀屋整体样板

本提交交付兽道溪桥—夜雀屋的整体场景样板，基于 `040e536`。最终v2.2已完成干净构建、Node22完整38组回归、真实宽景／屋后及低画质／缓存重入验收。它改善范围内的树形、灌木和地表，并保留合格建筑与路线；**整条兽道和主空岛的美术仍未完成**。

## 实际范围

样板限于既有兽道的x810–1145、z125–330，地面外观在边缘20米内渐退。连续土地、原道路、溪流及建筑位置保持；没有新增地区。博丽神社与香霖堂的合格成果继续保留。

所有目标树／灌木的原身份、树种、完整实例矩阵与颜色逐项保护。214棵树不是种植元数据604＋14；实际原兽道树共有568棵，范围外实例保持。复用已有叶片图像，新增4个树木材质和3个私有深度材质；地面变体有上限，不修改共享原材质。

夜雀屋只修原厨房浅窗和棚架，原屋台、演出角、客席与来源保持。固定食堂仍标为同人参考和本作补完F/P，不改写成原作固定住宅。新桥头工程与尺寸为P。

## 可复核的验收

实际同机位PNG：[原版远景](../preview/trail-scene-before.png)、[样板远景](../preview/trail-scene-after.png)、[样板屋后近景](../preview/trail-scene-rear.png)。两张样板图均来自v2.2冻结构建，没有用旧构建截图代替；宽景只追加一帧，屋后取得三张完全稳定帧。

基线为 `040e5369b1ef0d5f45242ff4e1193ab0874e2f2b`。固定宽景eye `[1030,140,35]`、target `[970,39,240]`、FOV49；溪桥近景eye `[852,43.2,203]`、target `[870,37.3,191]`。均为1280×720、DPR1、balanced、晴天12.5、动态／人物／标签／微光／反射关、AO开。

早期整景v1.1因迷彩地面、暗球壳树冠和桥头平台感拒收。v2的树形与地表已有可见改善，但缩短西接板后原桥纵梁露出约9.72厘米，仍未接受。CPU射线与浏览器源摘要精确绑定，确定是原梁外伸0.705米，未删除原梁来隐藏问题。

当前v2.1仅调整西接板既有首段坡度；原桥504／216三角、房屋和东端几何保持，公共接板仍240／112三角、38,016字节。原梁与新壳底最小净空约24.216毫米；372个地形叠合点和40条支座射线通过，最大探测高度差约11.904微米，阈值仍50微米。边界水平补射另记，不能称物理绝对零缝。修复后的真实溪桥首帧已确认凸块消失，两条接板与独立CPU描述精确一致，其余2291条源记录与v2逐字段相同。

v2.1屋后两条点状线对应厨房分层内盖，实际Float32背缘没有几何空隙。v2.2将9个石膏块的并体边界改为连续外壳，108→60三角，背墙为单quad；厨房外4183个既有修复三角及窗木逐字节保持，18条背墙射线和6处凹窗深度通过。桥v3、树木和地表不变。

最终屋后图确认灰泥背墙两条明显白线消失；木侧墙窗上下仍有轻微分块细线，作为非阻断表面精修项保留。此验收不宣称整栋房屋或所有区域细节已完成。最终宽景已与原版实际并排审阅，树冠与地表方向接受；完整运行与回归状态另列。

干净源码重建HTML为36,135,748字节，181项输入，SHA-256 `a2b85c427607f0d74088c796a8881ea3892bb619e4eba48091488e9c0bcb2a5d`。最终Node22.23.3完整回归退出0，38组通过，807.275秒；输入仍与冻结版本相同。旧v2.1的38组（799.056秒）和旧结构v1的36组仅为历史证据，见[结构阶段记录](../tools/trail-upgrade-review.json)。最终结果见[整景审阅记录](../tools/trail-landscape-review.json)。

Chromium151／SwiftShader取得7张最终PNG：屋后三帧完全稳定、固定宽景一帧、低档／冷代理／原生回包三帧。一次原生清缓存删除143条详情，249份被观察数组的几何、索引、对象及视图引用均归零，2150条永久记录保持；回包后的2293条源记录逐项一致，低档前后PNG逐字节相同。完整源JSON仅请求／构建／回收统计变化。旧A组和神社脚图仍明确绑定v2.1，最终核对2292条非house记录一致，厨房由独立CPU描述保护，没有冒称全部机位重拍。

最终三个浏览器会话均退出0并正常关闭，无新增脚本、着色器或上下文错误；各自保留一条未归因404，与基线分别记录。首次低档检查因验收脚本无条件要求阴影开启而退出1，0PNG且尚未清缓存；按原生产低档禁阴影策略修正检查后，完整功能段通过。应用没有为通过该检查而改动。

## 成本与限制

最终v2.2固定宽景的总调用272→360、提交三角739,800→627,638，驻留几何属性11,630,716→11,607,860字节；屋后总调用932→992、三角2,272,430→1,546,170，属性63,577,490→64,903,074字节。两机位纹理数量都保持12个，程序分别增加10／9个。相机、设置、灯光和场景状态逐项一致，计数使用相同字段。

此前v2.1溪桥总调用164→216、三角2,055,141→1,239,185，属性11,720,700→12,998,288字节；这条仍标为旧构建实测，不冒充v2.2新冷会话。屋后相机覆盖更多场景，不能拿其驻留值与溪桥直接比较；区外两张图像虽与原版完全相同，也不代表离屏阴影或缓存成本相同。

树木源展开近景221,808、远景78,420三角，204棵冷总览19,584三角；灌木另计。模型预算、整帧提交与物理显存不是同一指标。这些是软件WebGL的画面和资源证据，没有实体设备FPS结论，也不宣称整体更流畅；推广前仍需控制绘制调用及近景属性增量。原生Worker等待期间的实心粗冠代理与公共地色明显更简化，这是保留的LOD视觉代价，不宣称加载前后细节一致。
