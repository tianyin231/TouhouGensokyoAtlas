# 迷途之家：缓坡旧村与猫的局部选景

> 本轮基线：已合并PR #2与#3的 `d1efe95f396a4ddc57f81305ea3f40226feda764`。版本仍为0.29.0；仅处理 `mayohiga`，不是妖怪之山剩余组全部完成。实测数据与未测项见[当前状态](current-status.md)。

## 来源与边界

本轮读取 [迷途之家场景索引](https://thbwiki.cc/迷途之家) 中的社区场景整理及《东方文花帖》橙条目原作文字转录。原作转录支持山中荒村、猫群和橙喂食／收服猫群的关联；场景索引整理了瓦屋、农田和红鸟居。**未获取原始游戏背景贴图或完整原书插图进行逐图比对**。不以民俗中的同名传说直接推导本场景外观。

T代表原作文字的社区转录；C代表社区整理；P代表本项目的工程构形。具体山址、三栋旧屋及一栋残屋的数量与平面、瓦型、背面、阶梯、田埂、6只普通猫与来路均为P。这里不是八云紫的家；没有移动蓝或紫，也没有改写原85人物记录。橙仍保留既有夜雀屋兽道访客展示；本轮新增的是独立的普通猫环境几何，不是人物立绘或新NPC。

## 实际制作

先在真实WebGL检查基线，确认选址只有连续坡地与旧树。第一稿位于较陡山腰，石基过高；实际看图后将村落移到南侧缓坡，降低基座高度而不改原地形。随后检查发现鸟居与荒田两个预设被树冠遮挡，调整机位而没有删除原树；它们的改前截图也按新机位重新采集。

三栋完整屋体分别采用缘侧、侧附棚与仓屋处理；第四栋有实际瓦面缺口、露木架和残窗。门洞有进深，侧窗由墙垛与窗框围合；背墙、地基与柱脚不靠单面贴片。普通屋顶可完整恢复；主屋另有可逆剖览，其他房屋的残损是固定设计而非剖切状态。屋内仅有简化地板、榻垫和少量木器，不是完整可交互室内。

新近远档按相同房址、屋体和树点位构建；近档追加瓦沿、木构、地基石缝、草丛和猫。材质只作用于本区，保留原太阳、天空、天气、时段，不增加点光源或持续动画。猫为静态小几何，轻量档会隐藏近景猫与细小植被，不假装已实现动物行为。

`SurfaceContact`只抽取本区实际显示的近／远档地形三角面，传给原生Worker。基座底缘分别低于两档地形，屋面和地板高度近远相同；道路分别匹配两档地形并复用源地块的显隐条件。原地形、旧树、既有地区总览包与神社源码字节不变。公共道路在总览层保留，详情回收不会令来路消失。

入口接路终点为原圣域中心线中的 `[-1460,-1180]`（工程坐标P），与4条村内支路分开；支路终点对应各屋阶梯足部。只证明几何连接与展示连贯，不声称已有建筑碰撞、NPC寻路或完整幻想乡地理测绘。

## 后续范围

当前为局部选景，不是用户已认可的美术终稿。原作背景外形精确比对、更多差异化旧屋与荒废痕迹、猫行为、完整室内与碰撞尚未完成。秘天崖、圣域和浅间净秽山已合并，但此前复杂跨区回收后轻量档的上下文丢失记录继续保留；本区专项通过不能自动把共享问题标为修复。

下一组仍有天狗聚落、瀑后洞穴／黄瓜田、幻想风穴、山麓间歇泉／地狱谷、地下中心与芍药田等7项。本轮没有给它们绑定普通山地或沿用无关建筑充数。
