## 2. 两张实际三维场景

`currenthell / hell_present`：风蚀低谷在高低灰红地层间穿行；西侧断层岩脊和东侧缓坡给出中景高差。成组骸骨、长骨、肋架分布在路径两边，有朝向、俯仰和半埋差异，专用近景保留眼窝、鼻孔、颅腔与下颚间隙。骨件是程序化通用遗骸，不映射到任何角色或真实受害人；没有血肉画面。无建筑、桥梁、刑具机关或熔岩城。

`avici / hell_avici`：更平缓的暗色荒地和稀疏灰骨，没有红风带、微尘运动、普通居民或生活设施。切换到无间后不带入主图风暴。两图都有延伸到雾后的地形，不摆成地表上的小展台，也不挖穿幻想乡。

近景骨件有颅壳、内部表面与开孔，不把两个黑色贴片贴在圆球上充数。总览采用简化轮廓，不先构建详情再降面。当前详情为合批的重复原型，不宣称已经实现GPU实例化或骨骸交互。

14个机位覆盖总览、浅道、埋骨旷野、头骨近景、岩脊、盆地、逆向观察、暴风区域、风带下方、TH19两项关联、无间总览／灰骨／暗处。暴风使用额外弧形风带和增强的局部气氛，普通机位恢复；是艺术示意，不是流体模拟或精准气象。

此处没有复刻所有作品中的地狱，更没有穷尽所有地狱种类。无间仅为既有`hell`的子选景，不增加一个未经目录讨论的地标。导览可以返回彼岸、畜生界，但按钮不等于正式物理通道或已知固定路线。
