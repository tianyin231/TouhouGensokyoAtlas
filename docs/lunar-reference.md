三图的 `poly` 为空，不进入地表 `placements`，不改变任何地表道路或载入边界。它们也不会继承旧仙界的总览缩放／偏移。月球只是独立场景，不会插在山顶、辉针城或旧地狱之间。

目录接入6个已有ID：`lunar_capital`、`watatsuki`、`lunar_peaches`、`fertility`、`tranquility`、`kaian`。`dream`是更大范围，保持未完整建成；`lunar`总括条目也不因本轮片段而算全域完成。没有把《锦上京》涉及的幻想乡地理迁到月面。

## 3. 建筑、近景与事件

城墙有完整背面、转角及真实门洞；前门三开间支撑楼台，角楼有地基，殿堂和宅邸由台阶承托。房屋有实体墙段、窗孔、纸窗内退、窗棂、柱脚、曲面分段屋檐、瓦垄与脊饰，而不是立面图片。绵月宅茶室可透过开间看向同一场景的前廊与庭院。除茶室外没有实现全部住宅内部、家具交互或碰撞行走。

东侧城门到桃园的铺路随坡降低，海岸保留浅滩接触和石体，水域没有普通动物装饰。桃树是分叉木干与分组花冠、少量果实；它们不是自带农场系统的交互作物。茶具、九路将棋盘、矮凳及捣药器具属于P日常陈设。

日常机位保留绵月姐妹关联；TH15封存机位隐藏日常陈设和日常人物标记，出现探女的历史活动关联。它不意味着四位人物同一时代在同处。树形、建筑及封存色调不能证明原作在某一秒的完整画面。

月面天空、抽象程序地球、海面高光和梦带均为自行编写的材质。地球纹样不是地理贴图或科学测量；水面蓝色高光不是实际平面反射，也不是结界传送机制。风波、鹤形和梦带共用暂停时钟；封存事件静止。

## 5. 工程与预算

`project.json` 追加 `src/lunar.js`，同一代码进入主线程与原生Worker。渲染器在辉针城之后继承；月面独立天空、光照、海面、封存着色只在相应空间生效。返回幻想乡恢复原天气状态、太阳参数、阴影偏移和原天空，不把用户选择的雨天改掉。

`data/lunar.json` 在构建时以受限字段追加资料、别名、来源及新人物。原 `data/atlas.json`、`characters.json`、`expansion.json`不改；禁止覆盖地点ID、地形、原关系或原人物。模板、主线程、Worker和目录使用同一次编译结果。

## 6. 验收入口及限制

```sh
python tools/build.py
node tools/check.mjs
# 可选；额外安装 Playwright 和 Chromium，不是离线构建依赖
python tools/check-browser.py
python tools/check-lunar-browser.py
```

Linux系统Chromium需要可用显示服务器时可传 `--headed --chromium /usr/bin/chromium` 并在Xvfb下运行。`--content`是环境不允许本地HTTP导航时的替代装入方式：将完全相同的构建HTML装入about:blank，保留真实Blob Worker，报告明确记录它不是HTTP／file://验收。不能通过关闭管理员策略把失败改写成成功。

固定测试 `check-lunar.mjs` 检查新几何、13个继承源码／资源文件（含旧检查器8个）、原53个人物、179地点、六项映射、14个机位、表里空间、预算和确定性；`lunar-baseline.json`是经审阅的期望，测试只读，绝不自动更新。

浏览器报告写在忽略的 `dist/` 下，绑定成品SHA，分别记录脚本／着色器错误及外链图片失败。检查覆盖导览控件、近远互换、14机位、空间／时代互斥、共享时钟像素、路径相机采样、旧区返回、取消构建、三轮缓存回收及窄屏布局。路径采样不等于完整录像、碰撞检测或逐顶点穿插证明。

具体本轮结果见[当前状态](current-status.md)。SwiftShader验证不代表独显或手机FPS，也不代表最终美术已经得到用户接受。
