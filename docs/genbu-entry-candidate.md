## 已见问题与实现

基线两排柱列在南口齐截，缺少有宽度的岸脚；水尾是裸露的矩形蓝片；乡间土路与细木径、桥头缺少完整落脚。第一稿将原终柱递降、实际冲突柱降到木板底以下，再整形原地面承接两岸和来路，从两档共有 `z=-524` 水断面接出窄尾。没有新增石罩、散草、树身份或纹理。

- 原 144 根 native 柱中改变 37 根：原批准的 `z>-562` 34 根，以及实际侵入南段通行体的 `native:west:layer2:18/19/20`（原 ordinal 72/73/74）。原 XZ、底面、六角身份保留；刻线随柱缩高，原帽整体平移。13 根已证实侵入木路或桥的柱体／帽，最高点留在实际原木板底以下至少约 4 cm。
- 冷总览独立匹配 64 根柱中的 14 根，不假定与 native 一一对应。其中 8 根具有原桥路冲突，按冷层真实索引与实际木板底处理。未改柱、洞口、工作台、桥板、栏杆与上游设施保持。
- 原路径点位、样本和连通不变。末端土路宽度由 3.1 m 接至原木径 2.5 m，完整两角与原首板前缘一致；末端横截面移到原首板前缘，原木板不移动。
- 原近面仅在既定范围内整形；北侧水尾处重建确有位移的原三角，裁分受原真实三角平面约束。远面使用原远面加新近面与旧近面的增量，保留已有近远高度偏移。未变原面保留，避免新网格把原零位移地面改形。
- 39 株 native 树的矩阵、原型、颜色不变；四个域内根和三个脚印跨域的根有明确保护域，公共原树也保护。原路边小草／灌木仅刚性 Y 跟随实际地面差，不逐顶点拉形、不新增。
- `manifest.genbuEntry` 独立保存新旧实际近面及新水尾 contact；Terrain.height 链式返回旧 query 加实际地形增量，保留旧 query/near 偏移。新水尾查询只限本域和原玄武涧类型，其它位置回退原查询。原 `z=-526..-524` 水面存在而旧查询为 false 的问题明确继承，未称整溪查询已统一。
