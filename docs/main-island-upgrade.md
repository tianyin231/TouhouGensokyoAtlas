## 验收约束

- 使用固定相机、相同时间／天气／画质的真实WebGL对照，检查背侧、低角度接地与区域入口。几何预算通过不能代替画面验收。
- 保留连续土地、原路线和已标记的来源；公共道路、环境与承托不能随详情缓存卸载消失。
- 贴图对照记录实际可见集、LOD、全部绘制阶段、阴影和资源增量。生产帧时序与强制取图分开报告；软件GPU结果不换算为实体显卡或手机FPS。
- 每个正式里程碑运行构建、Node22检查和相关浏览器验证。固定几何期望只在明确审阅后更新，不在测试时自动刷新。
- 仅提交必要源码、精简报告和少量对照图；原始批量截图、临时构建与性能原始帧保留在工作区。
