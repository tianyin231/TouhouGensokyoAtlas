## 2. 实际三维场景

独立`senkai_kasen`空间使用`kasen`区域ID、空归属多边形及恒等展示变换。未添加地表placement、山上门口或常开空间门；返回旧地区时沿用原场景、相机模式和天气选择。与神子仙界的门廊、月都与天界均分开，不依照相同XYZ把它们叠成真实楼层。

住宅包含三层收分体量、厚瓦檐、脊线、柱梁、环廊、台基、侧梯和较低附屋。首层正面的两处圆窗有真实开孔、墙厚、木棂及内侧视野；不是把圆形贴图贴在实墙上。首层门洞留空，背面有完整墙体。上层可观察窗列和环廊；并非每一面装饰窗都能开启，也没有穷尽三层全部房间。

书室含逐层书架、成组独立书本、桌椅、茶壶茶杯、灯具与无字圆相挂轴。挂轴属于P陈设，不冒称原作十牛图的精确内容。从圆窗看出去仍是同一庭院和曲径，不用图片切换冒充室外。

石铺庭院、草坡、花群、分叉树木与松形树冠构成院景；支路通往有桥台、木板和栏杆的木桥，以及后方开放鸟栖和浅槽。两只通用静态鸟形只是环境补充，不作为已完成的务光、竿打角色模型；黄帝、万岁乐、彭祖等所有动物没有在本轮全部建出。桥梁和河涧是P庭园地貌，不归并到原作已命名水系。

远山改为有鞍部和相互重叠肩坡的连续高度场，不用重复圆锥充当群峰。中央低谷与河槽分开，山体代理不会覆盖院内的水面。路径使用共边网格，并有连续相机采样点；这些不是碰撞网格或导航寻路系统。

## 3. 漫画、夜庭、水墨与事件

14个机位覆盖总览、入庭、楼阁、前庭、书室、窗内望庭、二层环廊、背侧、鸟栖、木桥、夜庭、TH155水墨、48话阵纹和首层剖览。

漫画选景显示暖色住宅与庭园。夜庭保留同一几何，仅改变本空间天空与灯光，不改变地表天气。TH155选择隐藏漫画住宅、庭院器物及人物的漫画时期标记，保留本作山川、树木和薄雾并使用水墨色调；共享地形是P展示组织，不是两种作品的地形完全一致。水墨仍是三维模型，不是山水画全景贴图。

阵纹只在事件机位显示，地狱场景及物理传送未接入；剖览只隐藏上层和遮挡书室的正面／屋面，正常机位恢复。没有角色舞蹈、剧情演出、所有建筑碰撞或独立仙界地面行走。
