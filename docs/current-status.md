## 2. 核验与状态口径

“已实现”指有实际生成代码与维护者入库内容，不等于最终美术合格、所有通路已运行验收或原图已成功加载。本轮读取了当前树、配置、构建与检查脚本，以及旧地狱两个模块；两个地底模块在源码拆分前后Git blob相同，维护者的新实现得到保留。

本次文档整理没有重新运行当前地图的构建、集成检查、浏览器、硬件帧率或全场景碰撞测试。`tools/check.mjs` 是真实存在的检查器，但“已审阅代码”不是“本次执行通过”。`preview/` 是维护者提供的已有图片，不是本次新截图。旧对话的测试数字不复制成当前成绩。

对人物表另做了数据身份核对：将可访问基线中的原表按当前JSON格式序列化，其Git blob与仓库 `data/characters.json` 的 `e022ebe9e49c4f71af2cc27248ef785bf2bf35b8` 一致，含51条唯一人物记录，未有 `space: oldhell` 项。该核对不是浏览器验收，也没有改动人物数据。

## 4. 维护者已提交的旧地狱

当前 `oldhell` 是独立地底坐标图，在一个详情包内构建，不把全部地狱世界等同为这一块。`G.IMPLEMENTED` 接入9个地点ID：`old_hell`、`deep_road`、`parsee_bridge`、`old_capital`、`chireiden`、`hell_spa`、`blazing_remains`、`reactor`、`blood_old`。

| 预设ID | 场景及源码可见内容 |
|---|---|
| `hellOverview` | 层叠旧地狱总览；剖览状态隐藏外围洞壳遮挡 |
| `hellBridge` | 风穴方向下行深道、跨谷石桥、岩壁及灯火 |
| `hellStreet` / `hellRoofs` | 青瓦旧都、主街／横街、店面、后巷、排水渠及两处小桥 |
| `hellSpa` | 温泉街、温泉馆、石池、木廊和蒸汽 |
| `hellPalace` | 地灵殿前庭、喷泉、花坛、主体两翼、尖塔、拱窗与蔷薇窗 |
| `hellHall` / `hellGallery` | 实际大堂／回廊，棋盘地面、彩色地嵌、柱列、彩窗、吊灯和后部双楼梯 |
| `hellDescent` | 宫殿下方折返维护栈道与岩柱承托 |
| `hellBlazing` | 下层熔岩面、黑岩、旧设施、栈道、热烟和火星 |
| `hellReactor` | 星形维护桥、立柱、发光回路、球形热核和升降井架下站 |
| `hellBlood` | 更深支路、旧血池／油海、围岸岩石与灯火 |

**当前代码已包含地灵殿大堂、回廊及旧血池，不再是“外部宫殿＋预留血池”。**但完整房间群、可乘电梯、地表设施全链路和碰撞导航仍不能由模型推定完成。

源码工程高度：旧都约Y=-320，大堂Y=-282，炉区桥面约Y=-619、熔岩面Y=-652，油面约Y=-803。它们属于 `oldhell` 本地布局，不是与地表洞口逐米配准的官方深度。温泉街目前在旧都侧方；[旧地狱的社区索引](https://thwiki.cc/旧地狱)提到温泉街与炉区深度近似，这与当前布局需要进一步对照所选原作状态核实，不能把现有数值升格为一设。本次只记录疑点，不改动维护者模型。

渲染器已有独立地底环境、最多8个选近位置的点光源，以及大堂／回廊使用的局部投影灯；隐藏天空和雨。`hellZone` 是模型组织字段，不表示每个子区已独立Worker加载。

## 5. 资料、人物与核验缺口

当前资料延续179条地点、83条关系和22个工程锚点。旧地狱实现给9个地点建立映射与说明；研究数据、区域历史版本与 `project.json` 发布版本含义不同，不应全局替换。

人物数组实际为51条，但表尾的 `scopeNote` 仍写“50条”、`note` 还描述此前“新增10位”的阶段。这些是待清理的历史说明，不应作为当前数量依据，也不应通过全局替换抹掉有意义的历史来源。

地狱几何模块和渲染器没有新增人物数据逻辑，当前未有oldhell人物项。**不能把觉、恋、燐、空、勇仪、帕露西、山女、琪斯美等原图定位全部算为完成。**补人物时逐项核对当前表，区分职责、居所、活动、时代和未知坐标，避免重复人物。

原图联网成功路径与离线缓存必须实际验证；有网址不等于图片可用。现有集成检查器验证构建、脚本和地下数据的一部分，不覆盖全部美术、人物、连续路径和缓存压力。

## 6. 推荐接手顺序（尚未在本次实施）

先按新的构建流程为维护者版本建立浏览器与地区覆盖基线，保护源模块和 `assets/packs/`；再补地下人物／出处、核对连接和时空切换，之后考虑旧地狱子区分包、总览更新工具与中景自然化。不要重新导入旧HTML，也不要再次“恢复”已经补建的森林。

未全面建成范围仍包括现行地狱、彼岸／三途河、畜生界、冥界／白玉楼、天界，以及若干高山支区等。具体以新提交的实际构建入口更新，不把研究目录中的“存在”当成施工进度。
