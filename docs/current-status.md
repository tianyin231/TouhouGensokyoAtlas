## 质量与历史失败边界

实机中发现初稿石基过高后，改在缓坡布置而没有推平山体；鸟居与荒田预设曾被树冠挡住，已改机位并按相同新机位补拍基线。屋背、石基、柱脚、缺瓦和接路已看图，仍需进一步精修荒废痕迹、树形与林缘疏密。旧树附近的通行净空尚未建立碰撞约束。完整室内、猫行为、正式美术接受不在本轮完成范围。

**共享WebGL历史问题未被本区通过结果抵消。** PR #2复杂跨区／多轮回收后的首次轻量档曾有1次上下文丢失及8项着色器错误；该触发根因仍未确认。本轮不改恢复渲染器，也未重跑整个旧Asama压力套件，不能称问题已经根治。此前受控恢复和HTTP成功记录见 [接路与恢复交接](road-recovery-handoff.md)，秘天崖历史结果见 [Hiten交接](hiten-handoff.md)，神社／高地记录见 [此前状态](status-before-asama.md)。

实体GPU／手机FPS、长期压力、所有旧地区完整视觉套件与全地图夜景未重测；未获取原始游戏背景和完整原书插图作逐图测绘。场景来源和本项目的P布局继续分别标示。
