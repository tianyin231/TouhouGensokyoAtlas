## 2. 核验与状态口径

本轮实际恢复了中断前保存的月世界源文件，逐文件核对Git blob，并运行最终源码的构建、集成检查与浏览器回归；不把上一轮的报告作为本轮成绩。“已实现”仍不等于全世界最终美术验收。

构建与检查：主线程／Worker同源；179地点、原旧地狱62网格、原辉针城42详情网格均保留。月都65详情网格／165,044三角形、静海4网格／36,152三角形、梦径3网格／8,413三角形；三图总览共1,764,396字节。固定检查保护13个继承源码／资源文件、原地形锚点、原关系和原53个人物。新几何有只读期望值、确定性、有限坐标、单位法线与包围体检查；这些是源数组统计，不是硬件帧率。

最终成品SHA-256：`a7f5640248bcc3d553c8a5f1b88340845c715341a97b2b1875e0eedb122db5c3`。连续两次构建输出一致。`tools/check-lunar-browser.py`通过28项月世界检查，`tools/check-browser.py`在同一成品上通过26项继承场景检查；两份报告均绑定该SHA，均无JavaScript或着色器错误。

实际浏览器为Chromium 144.0.7559.96／WebGL2／SwiftShader，1280×900、DPR1、标准画质，在Xvfb中以有头浏览器运行。采用 `--content` 将完整构建HTML装入about:blank，使用真正的Blob Worker，不替换Worker、不绕过管理员策略。本轮没有验收HTTP或file://路径。尝试同时运行两套浏览器时，继承检查曾在装入页面阶段发生一次 `Page crashed`；随后单独串行运行同一成品通过。不能据此承诺低内存多实例环境。

月世界通过项：冷启动不预建详情、远近替换、14个机位、静海表里互斥、日常与TH15封存标记分离、非零时钟暂停及海面／梦径像素变化、真实鼠标旋转、别名与来源、四个人物独立坐标、12次桃园到海岸的连续相机采样、天气／阴影恢复、取消过期Worker和三轮缓存往返。三轮回收后新增详情均归零，记录的纹理数稳定为11、几何数为552；这是该测试的有限轮次资源计数，不是长期零泄漏证明。

继承回归覆盖辉针城8机位、森林、博丽神社、旧都、地灵殿大堂／回廊、旧血池、历史地下长廊与仙界，切换后天空与空间灯恢复；390px窄屏无页面水平溢出。截图来自同一最终成品，不使用生成图或旧截图替代。

绵月姐妹的原作肖像文件未取得，显示“原作图待核”。探女和哆来咪有已注明出处的原作立绘外链，但本轮未成功载入，报告保留失败状态；没有原图离线缓存，不称全离线人物版。

未测真实显卡／手机FPS、所有道路的连续录像、全世界碰撞、长期内存压力或全部房间。旧地狱温泉／炉心等本轮未逐机位新截图，但其源码与源资产固定保护。报告与截图输出到忽略的 `dist/`，不批量加入源码仓库。

## 4. 维护者已提交的旧地狱

当前 `oldhell` 是独立地底坐标图，在一个详情包内构建，不把全部地狱世界等同为这一块。`G.IMPLEMENTED` 接入9个地点ID：`old_hell`、`deep_road`、`parsee_bridge`、`old_capital`、`chireiden`、`hell_spa`、`blazing_remains`、`reactor`、`blood_old`。

| 预设ID | 场景及源码可见内容 |
|---|---|
| `hellOverview` | 层叠旧地狱总览；剖览状态隐藏外围洞壳遮挡 |
| `hellBridge` | 风穴方向下行深道、跨谷石桥、岩壁及灯火 |
| `hellStreet` / `hellRoofs` | 青瓦旧都、主街／横街、店面、后巷、排水渠及两处小桥 |
| `hellSpa` | 温泉街、温泉馆、石池、木廊和蒸汽 |
| `hellPalace` | 地灵殿前庭、喷泉、花坛、主体两翼、尖塔、拱窗与蔷薇窗 |
| `hellHall` / `hellGallery` | 实际大堂／回廊，棋盘地面、彩色地嵌、柱列、彩窗、吊灯和后部双楼梯 |
| `hellDescent` | 宫殿下方折返维护栈道与岩柱承托 |
| `hellBlazing` | 下层熔岩面、黑岩、旧设施、栈道、热烟和火星 |
| `hellReactor` | 星形维护桥、立柱、发光回路、球形热核和升降井架下站 |
| `hellBlood` | 更深支路、旧血池／油海、围岸岩石与灯火 |

**当前代码已包含地灵殿大堂、回廊及旧血池，不再是“外部宫殿＋预留血池”。**但完整房间群、可乘电梯、地表设施全链路和碰撞导航仍不能由模型推定完成。

源码工程高度：旧都约Y=-320，大堂Y=-282，炉区桥面约Y=-619、熔岩面Y=-652，油面约Y=-803。它们属于 `oldhell` 本地布局，不是与地表洞口逐米配准的官方深度。温泉街目前在旧都侧方；[旧地狱的社区索引](https://thwiki.cc/旧地狱)提到温泉街与炉区深度近似，这与当前布局需要进一步对照所选原作状态核实，不能把现有数值升格为一设。本次只记录疑点，不改动维护者模型。

渲染器已有独立地底环境、最多8个选近位置的点光源，以及大堂／回廊使用的局部投影灯；隐藏天空和雨。`hellZone` 是模型组织字段，不表示每个子区已独立Worker加载。

## 5. 资料、人物与核验缺口

当前资料延续179条地点、83条关系和22个工程锚点。旧地狱实现给9个地点建立映射与说明；研究数据、区域历史版本与 `project.json` 发布版本含义不同，不应全局替换。

地狱几何模块和渲染器没有新增人物数据逻辑，当前未有oldhell人物项。**不能把觉、恋、燐、空、勇仪、帕露西、山女、琪斯美等原图定位全部算为完成。**补人物时逐项核对当前表，区分职责、居所、活动、时代和未知坐标，避免重复人物。
