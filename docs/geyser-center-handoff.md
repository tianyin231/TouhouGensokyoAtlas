## 开工与来源

本地Git网络无法使用；从已挂载的前轮源码与补丁恢复工作目录后，逐项核对并确认Git树与远端完全一致，初始没有需保留的未提交工作。实际源码和浏览器显示原核聚变炉及其井架已建，目标地面位置只有坡地和树木。本轮保留既有炉心、井架与导航，不把它们算作新建，不从历史图片重造原工程。

[T：非想天则早苗Stage3—4](https://thbwiki.cc/游戏对话:东方非想天则/东风谷早苗) 的社区原作文字转录核对神奈子指示建造的研究中心、井口盖板与下层炉心。[T：琪露诺Stage3—4](https://thbwiki.cc/游戏对话:东方非想天则/琪露诺) 用于中心、通道与温泉关联。[C：间歇泉地下中心索引](https://thbwiki.cc/间歇泉地下中心) 整理智灵奇传6-2的圆筒塔、锚索、低入口屋、低围墙和平移门，以及非想天则绿灯石壁。原书／游戏背景图片抓取失败，**未逐图审阅原始美术**；C外观总结不能冒充原图测绘。

地面与井道分别保留版本出处，具体工程点(-1306,-409)、尺寸、机构、后侧和管路仪表均为P。数据使用旧值匹配证据修正，不改原atlas.json或原关系；E050泉区关联、E051炉心关联继续有效。选景可以相互导航，但地表未挖洞，地下井道未物理接入旧炉心；上下平台是检视状态，不是可乘坐的电梯。

## 实现及保护

`src/geyser-center.js`：真实开口圆筒塔、入口屋前后门、侧窗进深、厚屋面、锚索与埋地锚座。地基同时核对近远显示地形，不放置悬空平板。支路接原泉区(-1228,-423.5)端点，绕开旧树后进入打开的大门；四条近远公共路独立于详情生命周期，原连续地形、旧树和源包不变。

地下独立空间为 `geyser_center_inside`。约40米选取井段、上下环廊、中央平台、承托接桥、护栏、导轨与驱动头均为P。下层平台偏移28米时匹配对应吊索；盖板只在关闭机位出现。揭顶保留楼板，默认视图恢复顶壳。没有新建核聚变炉副本，也没有以本区代替原深道。

`src/geyser-center-renderer.js` 只增加本区材质，复用现有四盏focusLamps，离开后恢复颜色、距离和衰减参数。不添加纹理、离屏目标、额外灯光或动画循环。主线程／原生Worker同源登记在project.json，启动只构建远档代理。

`tools/geyser-center-baseline.json` 用SHA-256锁定继承既有geyser基线，再追加三项旧文件和一条旧导航，保护84文件／108绑定及完整人物数据。常规检查只读，不自动改期望；probe参数仅用于建模过程的独立几何检查，完整check.mjs和CI不使用probe。旧地区几何基线未修改。

## 复测

```sh
python tools/build.py
node tools/check.mjs
node tools/audit-landmarks.mjs
python tools/check-evidence-corrections.py
python tools/check-geyser-center-browser.py
# HTTP实际不可用时才显式使用完整文档替代路径：
xvfb-run -a python tools/check-geyser-center-browser.py --content --headed --chromium /usr/bin/chromium
```

浏览器输出在忽略的dist/geyser-center-browser-check/。最终33项通过；固定截图显式绘制，48位置道路连续推进与正常选择器／画质／尺寸段使用生产调度。五组地面对照固定机位、天气、时钟及质量；两帧暖场后强制刷新阴影取三帧，旧可见模型集合相等。原版不存在中心井道专景，不编造地下改前图。神社日夜各用新会话，原炉心另查；PNG均一致。

支路撞树、地下机位入墙、入口屋地基不足等初稿问题已修正，初稿与最终证据分开。期望组织调整期间的旧检查日志不作为最终证明；冻结后完整重跑并复核构建输入。旧泉区和冥界浏览器脚本同步中心已绑定的断言，但未把未重跑套件写成通过。

## 后续边界

地面建筑和设备仍偏简洁，树冠局部遮挡保留，外围旧林地与设施过渡需进一步打磨。未进行原作背景逐页测绘，不称用户美术验收通过。完整设施、无缝通路、动态乘梯、人物活动与碰撞均未实现。SwiftShader统计不能代替实体显卡／手机帧率；共享WebGL恢复代码未改，历史多区压力失败根因仍需另查。
