## 构建与生命周期

`src/wind-cave.js` 注册独立空间 `wind_grotto` 和地表短入口。地表位于工程点(-440,-552)附近，来路以原 `mountain-lower-path` 的(-105,-628)端点接入。近远公共路采样实际显示的地形三角面，原地形及旧树不改变；详情回收后公共路仍保留。

本作洞段长约144米，含弯曲下降地面、厚侧壁及顶壳、78处悬垂生长体、35处石笋、褶皱流石壁和3处浅水洼。入口短凹廊深约7米。这些是本作尺寸，不是原作测绘。顶根从实际近远档顶面采样，顶盖中心也按实际三角面定高；不是把一排悬空圆锥贴到解析曲线上。新洞内池岸降低底面，地表地形未切割。

固定静态检查保留438条通路与156处实际顶根接触测试、源预算、确定性及旧文件保护。开发过程中源预算和根部检查曾失败，修改新几何后通过；检查不自动刷新基线。旧冥界对未绑定锚点的断言同步移除已建立的风穴，新风穴检查接替验证其新入口与旧导航不互相冒充。

`src/wind-cave-renderer.js` 仅对本区使用岩、土、水及风尘材质，沿用原天气、光照及资源释放链。没有新增点光、纹理、离屏目标、Worker池或动画时钟。风尘用共享timeUniform，低画质隐藏；关闭动态保留非零时相。切回地表仍保留用户日夜和天气选择。

## 机位与检查

| 机位 | 目的 |
|---|---|
| windFoothill | 原山麓上岩隙入口与来路 |
| windMouth | 厚岩唇、凹廊、地面与遮挡 |
| windFoot | 岩脚、碎石与原坡面接触 |
| windApproach | 接回既有登山路 |
| windEntry | 洞内整体层次与石帘 |
| windDescent | 下降路线、转折及上方净空 |
| windCurtains | 石帘侧壁、根部与流石近景 |
| windPool | 浅水洼、低岸与石笋 |
| windNarrow | 洞段深处的收窄与有限范围 |
| windLookBack | 从洞内回望入口方向；非实时地表传送门 |
| windSection | 可逆隐藏顶壳，不删除底板 |
| windRear | 有限洞段背壳与底部厚度 |

## 后续限制

表里物理贯通、完整地下网络、玩家碰撞、落石物理、真实水力、NPC行为均未实现。洞口周边原坡面较空，洞内锥状石笋、顶根扩口与材质细节仍需精修，不称已获用户美术接受。

本区测试未记录上下文事件，不代表此前Asama／芍药／黄瓜长会话失败已解决。共享恢复模块未改，根因仍未知。实体GPU／手机FPS及长期压力需另测，不用SwiftShader静态计数冒充实际帧率。
