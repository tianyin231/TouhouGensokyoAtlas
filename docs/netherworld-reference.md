## 2. 场景与连续路径

独立 `netherworld` 坐标图采用恒等展示变换，空多边形不进入幻想乡的地表锚点或地形归属。没有在博丽神社、山体或月世界上空挖洞／悬置白玉楼。导览返回时恢复原地表、天气和旧空间。

幽明结界选景之后，122级有实体承托的阶梯沿同一坡面上升至山门与樱庭；道路、阶沿和低坡连续，摄像机不需要中途换图。122级是压缩展示值，不是官方长度。数据中的阶梯采样点不是额外休息平台；相机路径采样也不表示已建碰撞导航。

白玉楼以横向本殿和两翼围合中庭，保留侧背立面、台基、瓦屋面、厚檐、柱梁、窗棂和拉门。中庭是实际砂砾面、石组与松，不是水池图片。本殿包含可观察的榻榻米、拉门、柱梁、桌案与茶具；从室内看出去仍是同一张冥界地图。侧后服务建筑、陈设和内部开间均为P，不宣称全部房间可以进入。

普通樱树成组疏密布置；含西行妖在内共279株程序树，数量仅是本作资产配置。西行妖使用独立的曲干、粗根、分叉枝、封绳与围栏，默认没有花冠；只有TH07事件机位显示少量花苞。雪庭隐藏普通樱花／花瓣并给相应受雪表面着色，离开后恢复春季，不改变地表季节。

13个机位覆盖全域、结界、长阶、山门、樱径、中庭、本殿、缘廊、背侧、西行妖封印、将开事件、雪庭与本殿剖览。剖览只隐藏选定壳体与屋顶；普通机位恢复，不永久删除模型。薄云、幽灵和花瓣是局部景观效果，复用已有非零场景时钟，不是流体或真实灵体模拟。

## 3. 目录绑定不是施工进度

新增统一 `src/landmarks.js`。界面检索、选择地点和审计工具共用同一个显式解析器，不再依据一个研究锚点就跳到附近区域并显示“可浏览”。

| 既有模型补绑定 | 实际目标 |
|---|---|
| 妖怪兽道／米斯蒂娅屋台 | `trail`／`mystiaCounter` |
| 博丽神社仓库 | `shrineGarden` |
| 人里火警塔／外围农田 | `villageFiretower`／`fields` |
| 红魔馆庭园／钟楼 | `scarletGarden`／`scarletClock` |
| 紫之樱 | `muenzukaSakura` |

共8条修正。火警塔只新增针对现有实体的镜头，没有再建一座塔。幻想风穴、山麓间歇泉、圣域共3条没有已核实的专用场景，保留研究锚点及资料，但取消跳往守矢／森林的误导回退；选择时不移动当前相机。

179条目录中，导航覆盖从67变为77、待处理从112变为102，即 `67 + 8补绑 + 5新接入 - 3误导回退 = 77`。它不是“77处全部竣工”：世界总括、选景、已建构件、待建条目分别说明。移除错误回退不表示删除了模型；补绑也不表示本轮制作了8套新资产。

`node tools/audit-landmarks.mjs` 从本次成品读取同一解析器，写入带成品SHA的 `dist/landmarks-v0.21.md` 与JSON。全表作为生成报告，不复制进每个版本的源码文档。

## 5. 工程与验证口径

`project.json` 在已有模块后登记 `netherworld.js` 与轻量导航注册 `landmarks.js`，主线程与原生Blob Worker共用源码。新渲染器最后继承，只在自己的空间改变天空、局部补光、雪色和显隐；原渲染器及各已建地区源文件不改。

详情83个合批网格、362,268三角形、39,124,944字节顶点数组；独立低精度总览68网格、2,065,824字节。启动只生成低精度代理；近景由Worker按需生成，离开后可取消／回收并保留代理。原两份pack.gz字节不变。详情目前是一包，不是按房间联网下载，也不以源数组字节代称整页内存或物理显存。

离线检查保护19个继承源码／资源／数据文件、原65个人物及旧活动，读取人工审阅后的固定几何期望；测试不自动覆盖基线。旧魔界检查只把最终人数改为可扩展下限并限定其原8位人物的检查范围；本轮新检查精确验证最终67条，旧几何期望不变。

```sh
python tools/build.py

# 可选，另需Playwright及Chromium，不属于离线构建依赖

```
