## 2. 连续地表，而非另一个独立世界

本轮的`highland`属于`surface`。在原妖怪之山西侧山肩布置残雪高地，工程中心为X=-1120、Z=-1835，主体台地约Y=738；这些只是项目坐标，不是官方定位。新增路径从已有大蛤蟆之池附近登山支路延伸，经山坡抵达旧屋前，再绕行高地。

地形不再使用重叠的独立“草皮”盖板：启动时对原索引地形中受影响的顶点进行有限范围抬升，近／远两套地形保留原有共边采样。处理12个近远地形记录，范围外顶点和其他记录保持原值与引用；没有挖开岛面、改湖水或削去原高峰。更高的原山体保留，局部交接使用平滑抬升函数。

新增山路分别贴合原近／远地形的实际三角面，而不单用解析高度函数；道路按原地块的显隐规则组织，避免粗网格山坡上出现路面穿地、悬空或加载断路。道路和修改后的地形独立于房屋详情缓存，退出后仍保留。与原山路相接是P路线提案，不是官方测量路线。

虹龙洞仍沿用0.28完整矿道模块；导航按钮可带到矿内，但本轮没有配准出一个可以无缝步行进入的地表洞口。没有把旧屋旁任意开口叫虹龙洞，也没有因此把秘天崖、天狗聚落或整个妖怪之山判为完成。

## 3. 三间旧屋与赌场内外

高地布置一间主要选景屋和两间小旧屋。主屋有台基、台阶、带支撑的缘廊、实体柱梁、双坡厚檐、脊线、侧背墙及门窗开口；较小旧屋包含部分缺失的屋面与外露椽木。开敞侧窗、纸面墙段和门洞的表现分别处理，不将正面画片当作完整建筑。

室内有分板地面、梁架、低案、红垫、静态纸牌／骰子、小柜、纸灯和局部薄烟。门前的龙形烟管由立体管身、头部与小角构成，另有悬线承托，不依靠文字招牌识别赌场。

“开设之日”显示烟管、桌具、坐垫、纸灯、薄烟及山如关联；“散场之后”将本轮的开设陈设和人物标记隐藏，保留空屋结构。只选择一间旧屋示意，没有实际实现按日自动轮换场所、NPC聚集、赌局或剧情演出。剖览可隐藏屋面和主屋部分遮挡，普通机位恢复。

花甸包含有分叉／弯曲花梗、下垂成对花瓣和基生叶意象的小型植物，近景花簇细化，其余采用廉价轮廓；不是植物学精确模型或真实物候系统。漂砾、残雪色带和小屋形成中景层次，不把每块石头登记为新地标。

## 5. 工程与验收

新模块为`src/highland.js`、`src/highland-renderer.js`、`data/highland.json`；主线程／Worker由同一`worldBuilders`注册。原源包、引擎、地区生成器、相机扩展和Pages工作流文件不修改；高地新增材质与一盏室内局部补光，沿用地表天空、日光和天气。离开室内／关闭赌场／卸载详情时补光关闭。

```sh
python tools/build.py
node tools/check.mjs
node tools/audit-landmarks.mjs
# 可选；仅浏览器验证需要Playwright与Chromium
python tools/check-highland-browser.py
python tools/check-browser.py
```

`check-highland.mjs`保护48个继承文件、原84人物、两条历史访问、91个旧导航，以及地形锚点和关系。新固定期望检查近远几何、原索引地形的范围内修改／范围外不变、道路向上绕序、包围体、非退化面、单位法线、13个机位和93／86目录。期望文件由作者审核后固定，测试只读，不自行重写。

浏览器验证区分默认真实HTTP和`--content`内容装入，捕获页面及着色器错误。包含开设／散场、局部补光与矿灯的跨区切换、正常动画调度器的工具栏操作、缓存循环和窄屏；正常动画段不手动绘制或调用GPU等待。具体运行结果和失败记录见[当前状态](current-status.md)。既有快速切区着色器问题没有因新增场景而宣称根因修复。
