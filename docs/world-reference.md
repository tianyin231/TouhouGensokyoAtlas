# 世界观、地理与来源

> 既有调研的可维护摘要，整理于2026-09-28。不是官方测绘或施工图。当前实现见 [current-status.md](current-status.md)，原研究条目与来源以 `data/atlas.json` 为入口。

## 1. 证据、坐标与实现分开

本项目没有取得一张能统一全部地点、时代和比例的官方全图。《外来韦编》的地理专栏也是根据作品记述作位置推导，不应当作每个地区精确坐标的授权。[地理考察转载入口](https://thbwiki.cc/东方外来韦编/2018_Spring!/幻想乡地理)

一条资料分别记录地点存在、相对关系、具体位置、建筑外观和时代。地点是一设，不等于我们画的道路、背面、庭院和尺寸也是一设。游戏关卡先后顺序不自动证明直线相邻；飞行、洞道、边界、仙界出入口也不能全部画成普通道路。

| 身份 | 使用方式 |
|---|---|
| 原作文本／实际画面 | 写明作品、章节／关卡和版本；作品中的传闻仍保留不确定性 |
| 转录／中文译文，历史资料常记T | 记录原作品和转载入口，不能冒称亲自检查了整本原书 |
| 社区索引／整理，历史资料常记C | THBWiki等用于查原出处，C不意味着全部原图已核验 |
| 地理推断 | 写理由及可调整部分，不升级成确定方位／比例 |
| 指定同人F | 记录具体作品与版本，不笼统叫所有同人共同设定 |
| 本作补完P | 工程尺寸、道路、站位、地形、未见立面和展示布局 |
| 未知U | 保留待核，不为了填满地图虚构住宅、入口和坐标 |

不得未经迁移改写已有字段语义。研究目录的存在与运行 `G.IMPLEMENTED` 的浏览入口是两回事，模型完成度不从资料收录数量推导。

## 3. 命莲寺—大祀庙—神灵庙

来源入口：[命莲寺](https://thbwiki.cc/命莲寺)、[命莲寺墓地](https://thbwiki.cc/命莲寺墓地)、[梦殿大祀庙](https://thbwiki.cc/梦殿大祀庙（场景）)、[神灵庙](https://thbwiki.cc/神灵庙（场景）)。

既有研究与实现采用的时空规则：命莲寺在人里外，寺后墓地对应TH13时期地下大祀庙；神灵庙关联大祀庙内部的特殊空间。后续迁址状态将神子道场与大祀庙放入独立仙界，并将迁址梦殿置于主道场左后方。**这是本项目应保留并继续核对出处的版本区分，不把两种时代的副本当作同一时刻两个住处。**具体迁址过程、内部关系和左后方结构应按选定原作画面核验；本次没有补做全部原图测绘。

用户另指定山寺登高感及《东方夜雀食堂》参考，本作在原村外锚点建立山脚—山门—山腰—正殿—墓地层台，地下采用连续临水柱廊、横桥和莲池。**局部山势与廊道尺寸属于F/P，不因此成为官方海拔，也不把命莲寺搬到妖怪之山。**

指定同人参考：[DLC3开发者商品页](https://store.steampowered.com/app/2191950/)、[v2.3.2玩家流程](https://www.bilibili.com/read/cv21129506/)。历史调研使用可获得的局部宣传与文字流程，不声称提取或逐格测绘了两张完整游戏地图。

检索可接受“神灵殿”的用户习惯写法，但资料与显示区分神灵庙、梦殿大祀庙与地灵殿。迁址仙界不等于天界，历史地下也不是旧地狱。

## 4. 旧地狱及其他地狱不能混同

主要索引：[旧地狱](https://thwiki.cc/旧地狱)、[旧都](https://thbwiki.cc/旧都)、[地灵殿](https://thbwiki.cc/地灵殿（场景）)、[灼热地狱遗址](https://thbwiki.cc/灼热地狱遗址)、[核聚变炉](https://thbwiki.cc/核聚变炉)、[旧血池地狱](https://thbwiki.cc/旧血池地狱)、[刚欲异闻场景](https://thwiki.cc/东方刚欲异闻/场景)。

旧地狱仍有旧都社会生活与废弃设施，地灵殿和下方灼热遗址有上下关系。旧都不是每条路都铺熔岩，地灵殿不是通用红砖旅馆。当前工程建立深道—旧都—宫殿—灼热区—炉心／血池支线；高度、路线和洞室形状属于P。

现有代码将温泉街放在旧都侧方；社区索引另写温泉街与炉区深度近似。此处保留为**待按原作状态核对的布局疑点**，不把当前数值当一设，也不在文档任务中擅自改模型。

- 幻想风穴、地灵虹洞、间歇泉地下中心是不同入口／设施。地灵虹洞不是高山虹龙洞，索道也不是入地底电梯。
- 地灵殿下的灼热遗址、核聚变炉、旧血池／油海分别建立身份，不用一块红色平面替代全区。
- 旧血池的油海表现参考《刚欲异闻》，不是旧作血之湖；不同淹没事件和时间状态不能随意并存。
- 现行地狱、彼岸／三途河、畜生界与灵长园不是旧都下方必然相连的几层。[现行地狱](https://thbwiki.cc/地狱)、[畜生界](https://thbwiki.cc/畜生界)
- 当前 `oldhell` 是独立工程坐标图，未凭负Y值就完成地表入口的精确配准；命莲寺历史地下另属一套资料关系。

## 6. 人物与指定同人的边界

原图身份、地点关联和P站位分别记录。莉格露、露米娅、橙在夜雀屋周边按同人访客／本作展示处理，不迁移住所。响子和米斯蒂娅的道路演出有[求闻口授鸟兽伎乐报道](https://thwiki.cc/东方求闻口授/幽谷响子%26米斯蒂娅·萝蕾拉（文文新闻）/中日对照)作为索引；舞台尺寸和停车点仍是P。

八云紫住宅未定位，迷途之家不能等同八云宅；普通歇脚棚不是妹红家、茶铺不是鲵吞亭、书摊不是铃奈庵。神子阵营的历史关联与现居状态分开；原作像素绘不伪造为全身立绘。原作图像权利与Wiki文本许可分开，不因可访问便视作已获商用／再分发授权。

早期参考还包括[幻想乡地理考察](https://yotogiluminary.wixsite.com/website/post/000014)、[TouhouCraft连续地图](https://www.planetminecraft.com/project/touhou-gensokyo/)、[东方夜雀食堂](https://store.steampowered.com/app/1584090/)：分别帮助推导方法、连续游览和生活场景。它们不是统一比例官方全图，不把不同作者的方位／水系／尺度各取一块无条件拼接。

本页主要整理既有研究。本次重新查阅了神社、竹林、香霖堂、红魔馆、地理专栏、大祀庙／神灵庙和旧地狱的可访问页面；部分解析缺段，细部关系保留原图复核要求。其余链接是历史出处及后续复查入口，不声称本次逐页重新考据、取得全部高清图或测绘原作建筑。建模前应建立所选版本参考板，明确已见正侧面与本作补全部分。


## 8. 辉针城的本轮版本选择

0.18.0已新增实体空中天守，详见[辉针城考据与实现](kishinjou-reference.md)。TH145三层外形为主、TH14逆向内部为构造参考，背面、尺寸和房间是P；TH155两层山体版仅作版本对照，不混建。《夜雀食堂DLC4》明确标F，不作为官方餐馆、居民和道路位置。石垣向上、望楼向下，但地表不翻转、不割岛；锚点与飞行观察机位不是官方坐标。魔力风暴只作为可关闭事件示意。
