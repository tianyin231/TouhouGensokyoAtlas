## 2. 都市与古坟林地

`animal`是一张独立工程坐标图，城内道路、灵长园外部和林径在同一图上。89栋近景楼房按退台、分层或平顶组织；52栋外围轮廓刻意保持低精度。楼房有基座、门廊、侧背窗格、层间构件、女儿墙及少量屋顶设备。所有普通楼房无组织专名，不把其中某栋命名为鬼杰组、劲牙组或刚欲同盟总部。`animal_hq`保留U／HOLD，`hell`也仍未建。

园地采用单一锁孔轮廓及连续分级土垒，不用两个相交圆盘掩盖接缝。护岸、水沟、环行铺面、入口坡道和守备口为P补完。街区为园地和环道留出范围；守备口两侧台基保留中间通路，不横挡道路。窄铺面与窗面使用局部深度偏移，避免远视角下与承托面闪烁，不改变全图相机裁剪规则。

121株分叉树有独立树干及分组树冠，避开中心路径；数字是工程配置，不是原作数量。守备口和林径放置静态通用陶偶，头部有开口及眼口缺口，外观是P；它们不是磨弓肖像、可操控军队或AI巡逻。都市中的少量抽象灵体同样不是已定位原作人物。

“改造前意象”只恢复草木园地的历史展示，隐藏本作的科技门、陶偶与相关人物标记。它复用P都市和园地布局，不宣称已还原改造前的官方完整地图，也没有增加动物灵夺回后的另一套结局。

## 3. 电子遗产内景

`primate_core`是同一灵长园内部的独立展示图，而非另一个官方世界。原作没有可配准的室内尺寸，本轮不把地下层高、门后距离或高廊强行塞进某栋外部楼房。切换为导览，不是常开物理传送门，也没有向幻想乡地表挖洞。

内景有实体外壳、柱列、横梁、侧高廊、相接阶梯、中央层台、矩形构造与线路地嵌。两侧显示屏状面板和线路沿结构布置，不用全屏噪点冒充先进技术。无专名陶偶制作区包含桌腿、台面、架子、陶坯和工具；这是根据造形神职责作的P环境解释，不冒称官方工房施工图。抽象人类灵只作关联景物，不复刻剧情过场。

剖览隐藏屋顶、正面及右墙，切到普通机位恢复。窗口、门、楼梯与可浏览房间不等于碰撞行走、可交互制作、升降设备或全部园区内部完成。

## 4. 人物与数据保护

追加杖刀偶磨弓、埴安神袿姬两条，最终75位人物；原73位、白莲／爱丽丝两条历史访问、地表住所及原出处逐项保留。磨弓为园区守备职责，袿姬为TH17造形活动；两人只关联选定时期，不宣称实时行踪或当前住所。位置直接使用所属图坐标，不误采同一X/Z下的地表高度。

本轮已核文字出处，但未取得两位可核验原作肖像文件。资料显示“原作图待核”，不猜图片URL，不用同人或生成图替代。静态陶偶也不替代人物原图。构建仍可能访问旧人物外链，不称全离线人物版。

`data/animal.json`只追加允许的目录字段、来源和人物，不覆盖原atlas的地点ID、地形、关系或人物数组。显式解析器保留原84个入口，再加2个，当前为179项中的86可导航、93待处理；这是目录覆盖，不是竣工率。
