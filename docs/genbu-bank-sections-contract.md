## 同一地面、LOD 与查询

近景成品面是唯一造型依据。核心内的 far 使用同一控制面，属于明确修正旧 LOD 支撑偏差，**不同时声称内部 oldFar 不变**。只有外围接缝带回到各自旧 near／far；带内不得另外塑岸。外接带先按控制面最外一列截面／两端各一排定义，至少 8 m 宽；核心与接缝边界必须输出为可检查的真实折线，不能用事后点距离分类掩盖跨界三角。

域外及所有保护面，各自 LOD 原几何／属性保持；核心 near/far 同点高度误差 ≤0.0003 m，外边接缝相对各自基线新增误差 ≤0.0003 m。先记录旧近远偏差，再区分核心纠偏与外围保留。`z=-512` 必须同源裁分；每条不同 index 的记录使用独立 vertices 对象，不改通用 renderer 的缓存键。

新字段拟为 `manifest.genbuBankSections`，API 为 `G.GENBU_BANK_SECTIONS`。地面查询保持 **previousHeight + actualNewNear - actualOldNear**；零位移、域外与无新面时精确回退 previousHeight。旧 analytic/near 偏移不是零。compact contact 拟存同 XZ 拓扑的新旧高度与索引，其采样必须来自真实面；所有持久 typed buffer 均计入预算。原 native 构造使用去除此字段的 manifest，再按明确身份应用柱／水调整，防止树和设施随新 query 重定位。

新水仅从原两档共有 `z=-524` 断面向南建立，原水位 `Float32(39.414)` 不改。先建浅床与岸，再从相同控制面求唯一湿线；水和土共用 Float32 边点。水尾形状必须是完整浅洼收口，不先拉尖叶蓝片再裁掉。冷／native 新水几何由同一湿线产生。

`water(x,z,0)` 只在实际水三角投影内返回 `genbu-creek`；正 margin 允许向实际湿线外扩 `4×margin` 米，负 margin 从同一湿线内缩同距离，保留原接口单位。只在本地新水包络内替换本溪语义，其他水 type／域外返回旧值。原 `z=-526..-524` 有水面但旧 query 为 false 的差保持并记录；不声称整溪统一。原水位／类型与正负 margin 分别检查。

## 最终网格与预算

所有裁边先用共享注册表量化到 Float32，再清理重复共线点并三角化。生成面不得有 3D 或 XZ 零面积；不能简单删掉坏片而留下缺面，须同时核共同边与投影覆盖。普通土坡法线从最终焊接面求出；保留面使用原法线，不能用未受约束的函数导数替代实际几何。明显折坡只能来自预先列出的岸肩控制线，不能用极细片的角度作为设计效果。

硬预算不变：同机位 **≤+4 全通道 calls、≤+4000 提交三角、≤629145.6 B 唯一新增常驻源、0 新 texture**。公共／native 所有新数组、compact contact、持久 metadata 一并计账；Worker 临时副本与构建峰值单列，V8 slab 不当生产驻留。若超限，先减少无关裁分和重复存储，不缩岸幅或放宽保护。
