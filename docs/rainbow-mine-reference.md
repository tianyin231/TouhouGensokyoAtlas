## 2. 连续局部矿道

独立工程图`rainbowmine / mountain_mine`只组织地下展示，仍属幻想乡山中矿洞，不是一个新增官方宇宙。空归属多边形、恒等展示变换，不添加地表placement、不挖穿或覆盖原岛面。未来高山施工可另行配准入口，当前不冒称完成从守矢步行进洞的路线。

矿口内缘、拱形浅层、加宽道场、东侧支巷与深部采场位于同一图。主轨与支轨随坡下降，包含双轨、枕木、压板、道岔意象和止挡；支巷与主道留出实际开口，地面相接。坑木有柱脚、铁箍、顶梁及斜撑；屋顶与侧墙分开合批，可以隐藏洞顶后查看路线，普通机位恢复。坡度、长度、支护数量、轨距、岔线与灯具全部P，不作为铁路或采矿工程规格。

静态木矿车有开放车斗、内退侧板、底板、金属边框、四轮、轮缘、轴与连接件；并非实心车形盒，也没有可乘车或运输模拟。采样桌、纸张和小石样是工作陈设，独立于人物身份。没有为缺氧洞穴添加燃烧火盆。

深部矿脉由三维分面矿石与灰岩基体组成，发光强度受控；彩雾仅是薄层着色效果，边缘软化，不把整张画面套上彩色滤镜。细沟水面共用可暂停时钟，属于本作排水构件，不登记为新河流。有限片段末端收口并不表示矿洞全貌到此结束。

## 4. 工程与预算

新模块`src/rainbow-mine.js`通过同一`worldBuilders`在主线程与原生Worker注册；`src/rainbow-mine-renderer.js`最后继承现有渲染链。原地形、所有地区建模器、林缘与相机扩展、两份压缩源包、Three.js和Pages配置均保持。矿内只选最近8盏工作灯；离开／回收后关闭，地表雨天及阴影设置由原渲染链恢复。
