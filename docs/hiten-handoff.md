# 秘天崖：局部选景与复测

> 2026-09-30，依赖圣域PR #2的后续草稿。本次只处理妖怪之山剩余组的 `hiten` 一项，不是该组9项全部完成。

## 出处与边界

核对 [《虹龙洞》灵梦路线第二面对白](https://thbwiki.cc/游戏对话:东方虹龙洞/博丽灵梦) 与 [《黑市》第一市场场景说明](https://thbwiki.cc/弹幕狂们的黑市/场景说明) 的社区转录，以及 [秘天崖场景索引](https://thbwiki.cc/秘天崖)。转录T、社区整理C与本项目P分别标识。本轮没有逐帧审阅原始游戏背景图，不能称官方场景等比例复刻。

山腹林崖的身份和作品关联有资料依据；西侧工程位置、5组岩体、94棵树、崖肩轮廓、背面、大小、路形均为P。沿用伪天棚既有公共山路，不增加独立孤岛、瀑布、交易楼或山童总部，不与伪天棚／虹龙洞混算。

## 实现

`src/hiten.js`按区生成近远模型，`hiten-renderer.js`限制材料和局部风化处理，`surface-contact.js`提取近远地形的紧凑位置三角数组供Worker接地。只读原地形，保留所有原顶点和源包。接地数据127,440字节，不是把整张地形克隆给每个工人。

5组厚岩体的基部、背侧进入原山体；崖肩苔面、枝叶、石块与林下草木分批。近远树点位共用，低档与远处隐藏细草；没有新增点光源或常驻动画。首版修过岩面／树冠法线方向引起的条纹阴影。

8机位：hitenOverview、hitenFront、hitenFoot、hitenLedge、hitenBack、hitenPath、hitenNorth、hitenWide，覆盖总览、正面、岩脚、崖肩、背部、旧路和山脊。当前外形仍偏规则块状，周边原山坡较空；这不是已获认可的最终美术。后续优先整合岩体与坡面、改进中景层次，不靠高频噪声掩盖体量问题。

## 实测

最终浏览器成品：35,438,912字节；SHA-256 `6cf69ccc99c54f7108ac451cab3c812dc6debd95090f4a59cfb4cd1391d5ad9c`。

27项独立秘天崖浏览器检查通过，错误数组、上下文事件历史均为空。包括8机位、原生Worker与代理替换、原山路取样、目录来源、鼠标旋转、近远切换、5处旧景往返、日夜雨恢复、正常工具栏调度、Worker取消、3轮缓存回收、低画质和390px界面。该结果不能抵消依赖PR2全量Asama路径的失败。
