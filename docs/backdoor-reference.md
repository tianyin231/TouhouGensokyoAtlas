## 2. 主景与版本分开

独立 `backdoor` 图为空多边形、恒等展示变换，不进入地表归属、placements或研究锚点，不改变整块幻想乡。第五面主景和Extra共用本作门群布局，Extra有单独观察角度与时代标签，不能称为完整新增地图。第六面隐藏主景的上下地面、季节窗口及台座，只保留黑暗中的连续门扉、彩雾和微尘。

绿色门框有实体厚度、内退门板、分格装饰、背面、合页、门锁与把手。四季门提供开／关两套合页变换后的几何，按钮切换状态，不是每帧动画；第六面的串门可同样关闭。上下红黑平面承载纹样、环线和七星形装饰，上层可隐藏，普通机位恢复。小型表演台与装饰座椅为P补充，不命名为官方宫殿或住宅。

14机位涵盖门群、入境、春夏秋冬四扉、合页背面、关闭门扉、二童子活动处、座席、上层纹样、第六面、Extra和门群背侧。二童子只在相应主景阶段关联，第六面不显示她们的标记。环境没有碰撞、可穿越传送机制或角色舞蹈系统。

## 3. 四季窥景不是实时传送门

四扇主门后分别呈现夜樱、夏空、红叶、雪林。它们由本作程序化小型三维场景生成，有真实树木、路面、灯具与建筑／山峦；不是下载的图片或替代整张主场景的全景背景。它们只是季节性的P景观，不宣称是此刻幻想乡某地的精确视点。

首次加载详情并显示打开的主景门时，以四次离屏绘制生成四张有上限的纹理，然后显示在门框中。标准首次生成分辨率256×448，轻量128×224；已生成纹理不随画质切换立即重建，回收后按当前画质生成。没有每帧重绘、视角视差、递归嵌套或当前地表高模载入。关闭门可以遮住窥景，但仍保留其缓存直到详情包回收。

生成时每个临时小景的几何／材质顺序创建并释放，只保留四个渲染目标；退区并释放详情时清空材质map、销毁目标，重访重新生成。保存并恢复当前渲染目标、视口、裁切、清除色、阴影和色调映射状态。`stats.backdoorWindows`单独报告目标数、累计生成次数和本帧额外绘制数；原全帧计数不包含这些主绘制前的初始化pass，不能漏掉这项就宣称免费效果。
