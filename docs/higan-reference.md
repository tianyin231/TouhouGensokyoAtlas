## 2. 两张展示图和连续岸线

`shigan`承载中有之道、赛之河原和三途河此岸；`higan`承载彼岸花原与关口。两图为空多边形、恒等展示变换，不加入地表placements、不改山后地形、不挖穿原空岛。把此岸也放入展示图是工程组织，不是否定原作与幻想乡的相对关系。

此岸的道路从14个摊位间穿过，转向石滩与渡口；土坡、路缘和小码头在同一图上。岸边网格加密，道路沿中心线共享边缘，避免独立路段造成锯齿裂口；这不代表全路径碰撞验收。十八株柳树、花群和石数是程序配置，不是一设计数。

三途河没有跨岸桥，没有可乘渡舟系统；两个导览图也没有按官方米数配准。水面静缓、雾中尖石与苔冠是视觉表现，不添加瀑布激流或普通湖泊生态。船具有可见的空心内壳、侧板、舷沿、长凳、桨和缆绳，码头有支撑柱；非一块填满的船形盒子。

彼岸以红花、细茎和反卷花瓣塑造近景，远处逐层简化。花原和此岸摊街分开：候判的抽象灵体安静排列，不摆饭桌或宴会。无专名关口包含台基、柱列、屋面、过道、柜案、纸册与笔具，是依据职责作的P建筑补完，不给它登记新的官方地标ID。

16机位分别观察摊街、摊面、棚后、圆石风车、垒石小会、码头、船内、雾中尖石、花原、关口正面／背面／廊下以及回望水面。小会只在对应机位增加景物，切换恢复。水波、灵体和风车轻颤共用原场景时钟；未模拟风车轴转动、鬼魂行为或流体。

## 3. 人物与来源

追加小野塚小町、戎璎花、庭渡久侘歌、四季映姬四条，构建后73条。原69人物、白莲／爱丽丝两条历史访问、原住所与出处逐项保护。人物坐标直接使用自己的空间，不误采相同X/Z下的幻想乡山体高度。

本轮核对了文字和场景出处，但未取得四人的可验证原作肖像文件；显示“原作图待核”，不猜图像直链，不以同人或生成图替代。抽象灵体是环境几何，不冒充这些角色。其余原图外链按实际加载结果显示，不能称全离线人物版。

## 4. 构建、缓存和目录
