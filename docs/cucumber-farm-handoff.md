## 来源和设计边界

[T：东方铃奈庵第29话P12—17](https://thbwiki.cc/东方铃奈庵/第二十九话) 是社区提供的原作对话转录。P12—13标明黄瓜田和妖怪罕至的边远地方，P15—17记载收获、开垦实验以及从外来书籍学习栽培。这里不是瀑布旁的一小片普通菜地。未逐图取得原书插图作测绘，转录不等于原始美术资源。

[C：九天瀑布索引](https://thbwiki.cc/九天瀑布) 记载瀑后轨道洞穴通向黄瓜田。本作保留既有关系 `E028`，目录可往返导航；**没有把独立洞内选景挖通到本地地形，也没有实现完整运输线**。

地点存在由本轮T来源支持；原目录的“偏远种植与工厂环境”未提供可直接复刻的工厂形制。`data/cucumber-farm.json` 通过旧值匹配、来源类型和字段白名单的证据修正机制，明确纠正该表述，不改原始 `data/atlas.json`。

以下均为P补完：工程位置 `(-1960,-1310)`、五带弯曲种植行、中央通道、藤架结构、花叶果形、灌排水渠、蓄水槽、手轮、收获棚及其背面、篮筐小车和田地笔记。笔记没有虚构魔导书原页。没有宣称这是河童总部、工厂或角色永久住所，也没有新增人物。

## 几何与生命周期

`src/cucumber-farm.js` 提供共享原型的196株藤蔓、五带分段竹架、19棵不规则林缘树、开口收获棚及静态灌排设施。藤蔓具有折面裂叶、卷须、小黄花及圆润纵向果形。远档保持位置和尺度，减少叶片、卷须和果体分段。

棚柱、槽基的高度同时考虑实际近远档地形，柱脚向下埋入原地面；有台基、台阶、下梁、侧撑、厚屋顶、背面条板和正面开口。背面实图发现初稿斜屋顶后侧高于柱梁，已按屋面高度补正后柱、横梁、斜梁和椽条，新增8次近远档实际承托接触检查。渠槽与棚前通路相交处补有承托的木桥。揭顶只隐藏本区屋顶；轻量档隐藏台面、空筐等小物。

通往田地的公共路从原迷途之家山径端点 `(-1704,-1090)` 接入。路径为P，不是官方道路测绘。修正过最初贴近旧树的弯道，保留原树不移动。主路、支路在实际近远三角面上铺设；公共路径只存在于总览上下文，详情回收不能删路。没有推平山体或创建独立地表展台。

`G.SurfaceContact.prepare` 仅提取本区三角形坐标，通过原生Worker传递，不改原地形数组。新模块在 `project.json` 与主线程、Worker同源登记；启动只建立新增区域低精度代理，不预先构建完整高模。渲染继承层位于恢复层之前。只增加本区材质，无新增灯光、离屏渲染目标、纹理或动画时钟。

## 复测

```sh
python tools/build.py
node tools/check.mjs
node tools/audit-landmarks.mjs
python tools/check-evidence-corrections.py
python tools/check-cucumber-farm-browser.py
# 仅当HTTP确实不可用时，显式采用完整内存文档路径：
xvfb-run -a python tools/check-cucumber-farm-browser.py --content --headed --chromium /usr/bin/chromium
```

浏览器依赖只用于测试。输出为忽略的 `dist/cucumber-farm-browser-check/`。固定取图段显式绘制，正常选择器、静止、画质与窗口尺寸操作段依靠生产调度，不靠手动绘制或GPU同步推进。脚本保存所有启动后上下文事件并严格判定；不得以最终恢复了就说没有丢失过。

`tools/cucumber-farm-baseline.json` 为显式初始基线，检查不会自动改写。除本区数据外，保护73项继承文件、105条旧导航和完整人物数据。旧地区几何基线不变；旧检查仅更新实时目录计数及黄瓜田已具独立选景的断言。

## 质量限制

静态作物不等于采收系统；灌渠和手轮不模拟水力，小车不具移动、运输或碰撞行为。原外围低模植被、疏密过渡与土壤细部仍需继续精修。建筑碰撞、人物活动和完整运输线不在本轮完成范围。

继承的长时间多区浏览后切轻量档的上下文丢失问题没有在此重写共享渲染器解决。本区检查必须单独记录，不能替代全部旧场景、全部时段或实体GPU长期压力验收。
